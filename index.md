## 🛠️ How to use the tool

The tool interface contains three main sections to customize your prompt.

### Choose your model
Select the specific Claude model you intend to use. Different models have different strengths. Choosing the correct model ensures the output matches your requirements.

### Select your application
This section identifies what you want to build. You can select from common project types like web development, data analysis, or script writing. This selection tells the tool how to format its response for your specific project.

### Set your effort level
Define how much detail you need. A low effort level creates a basic outline. A high effort level provides detailed code structures, documentation, and error handling advice.

### Generate and copy
Once you select your options, click the "Generate" button. The tool displays your custom prompt in the text box. Use the "Copy" button to move the text into your clipboard. You can now paste this directly into Claude Code.
